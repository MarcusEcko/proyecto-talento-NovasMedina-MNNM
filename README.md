## 📦 Instalación y uso

Clonar el repositorio:

```bash
git clone https://github.com/marconovas/proyecto-talento-NovasMedina-MNNM/tree/master
```

Entrar en la carpeta del proyecto:

```bash
cd nombre-del-proyecto
```

Instalar dependencias:

```bash
npm install
```

Iniciar el proyecto:

```bash
npm run dev
```
